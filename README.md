# BLOCKWORLD – Releases

BLOCKWORLD ist ein Lernspiel für Android zum Lesen und Rechtschreiben auf Deutsch, in einer Welt aus Blöcken. Dieses Repository enthält nur die fertigen Versionen (APK). Der Quellcode ist nicht öffentlich.

## Installieren

1. Unter [Releases](../../releases) die neueste `blockworld-<version>.apk` laden.
2. Auf dem Gerät öffnen und die Installation aus dieser Quelle erlauben.
3. Updates immer **über** die installierte Version installieren, nicht vorher deinstallieren. Sonst geht der Fortschritt verloren.

Mit der kostenlosen App [Obtainium](https://github.com/ImranR98/Obtainium) lassen sich neue Versionen automatisch finden: in Obtainium „App hinzufügen“ und die Adresse dieses Repositorys eintragen.

## Prüfsumme

Zu jeder APK gibt es eine Datei `.sha256`. Unter Windows prüfen:

```powershell
Get-FileHash blockworld-<version>.apk -Algorithm SHA256
```

## Datenschutz

Das Spiel braucht kein Internet und hat keine Netzwerk-Berechtigung. Keine Werbung, keine Konten, keine Tracker, kein Mikrofon. Der Fortschritt bleibt nur auf dem Gerät.
